# akshit-salhotra.github.io

Personal site. Plain HTML, CSS and a small script, with no build step. GitHub Pages serves it straight from the repository.

- `index.html`: home (directions, work, achievements)
- `about.html`: bio, education, tools
- `assets/style.css`: palette (Stone & Moss, light and dark), layout
- `assets/site.js`: theme toggle, optional sound, word reveal, link scramble, dot cursor
- `cv.pdf`: add your CV here (not committed yet)

Preview locally with `python3 -m http.server` and open http://localhost:8000.

Deploy: in the repo, go to Settings, then Pages, and set the source to "Deploy from a branch", using `main` and `/ (root)`.
